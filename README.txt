Привеееет!

Окей, этот плагин позволяет создать набор комнат. И из набора комнат собрать полноценную локацию,
со случайными развилками, автоматически расставленными заглушками и так далее

---

Для начала работы создайте ресурсы: "ReadyLocationSet", "RoomsSet", а также "TileSet" (В проекте они уже есть
в папке "Test Resource")

---

Затем откройте RoomSetEditor (res://addons/libraryeditor/Scene Scripts/RoomSetEditor/RoomSetEditor.tscn), и
добавьте пути к вашим созданным ресурсам. Кнопки это: read - для чтения, write - для сохранения, clear - для записи

Отредактируйте RoomSet

---

Затем откройте GenerRuleEditor (res://addons/libraryeditor/Scene Scripts/GenerRuleEditor/GenerRuleEditor.tscn), и
добавьте пути к вашим созданным ресурсам. Для начала редактирования запустите проект на этой сцене.
Через add node и del node создайте локацию, учтите что ГРАФ СОБИРАЕТСЯ ТОЛЬКО ИЗ "Start Gener Node" (Вкладка "Tool")

Соберите локацию и сохраните

---

Затем откройте TestReadyLocationReader (res://addons/libraryeditor/Scene Scripts/Base ReadyLocation Reader/Test Ready Location Reader.tscn), и
добавьте пути к вашим созданным ресурсам. Выберете индекс локации которую хотите загрузить, сид и прочие настройки (см класс ReadyLocationLoader)

Нажмите Read Set для отображения локации, при каждом нажатии сид меняется (это можно отключать)

Сцена TestReadyLocationReader, это только пример того как можно загружать локацию, вместо это вы можете использовать
кастомные скрипты, фактически для загрузки нужно только иметь саму ReadyLocation и ReadyLocationLoader

---

Поздравляю, вы великолепны (ну. если все полуилось, если нет то можете рассказать мне об этом в личке,
ОСОБЕННО если в том или ином месте плагин выдал ошибку)
